# I Wrote Today: handoff

Last updated 19 Oct 2026. Owner: Emma Berat. Live site: https://emmaberat.github.io/iwrotetoday/
Repo: https://github.com/emmaberat/iwrotetoday (branch `main`, deployed by GitHub Pages).

## 1. What it does

A one-tap daily writing check-in. No writing happens in the app; it only records that you wrote.

- **"i wrote today"** records today, then shows a one-word celebration in another language (with the language in
  small brackets) for about 2 seconds, then a daily quote from a novel with a "buy this book" link.
- **"i didn't, but i will tomorrow!"** shows a "treasure for your word hoard" message, then an unusual word.
- **Streaks:** at streak lengths 3, 7, 14, 30, 60 and 180 days (`MILESTONES` in `index.html`) the quote is replaced by a craft quote
  from a writing book ("you've written for N days! here's some writing wisdom…").
- **My writing days:** a calendar of days written.
- **Daily reminder:** in the store apps, real phone notifications. In a browser, a downloadable `.ics` calendar
  file (the original behaviour).
- **Share and rate:** the how-it-works page has "share this app" (the native share sheet in the apps, the browser's share
  or copy-link on the website) and, in the Android app only, "rate on google play".
- **How it works / intro / privacy** pages. Lowercase "i wrote today" on the how-it-works page is deliberate.
- **Smiley doodle with "EB" initials** in the bottom corner of each page. It hides itself when it would overlap
  content.
- **Red icon badge** (store apps): reminders that arrive from 18:00 put a red "1" on the app icon, cleared on check-in.

Quotes, celebration words and the Bookshop affiliate ID live in `content.json` and can be changed without a
store update (see section 6).

## 2. Tech stack

- **App:** one hand-written file, `index.html` (HTML, CSS and vanilla JS, no framework, no bundler, no build step
  for the web version).
- **PWA:** `manifest.webmanifest` + `sw.js` (network-first service worker, versioned cache).
- **Hosting:** GitHub Pages, served straight from `main`.
- **Native apps:** Capacitor 8.5.3 wraps the same files for iOS (Swift Package Manager, no CocoaPods) and
  Android. Node 22 or newer required. Plugins: `@capacitor/local-notifications` 8.3.1 and `@capacitor/share` 8.0.3, used
  without a bundler via `window.Capacitor.Plugins.LocalNotifications` / `.Share`. Icons and splash are generated with `@capacitor/assets` 3.0.5.
- **Fonts/images:** system Georgia font (no web font downloads); images are local SVG/PNG.
- **Tests:** none in the repo. During development I used throwaway Playwright scripts (Chromium, mocked clock,
  mocked Capacitor plugin). They were not committed.

## 3. File structure

```

sw.js                   Service worker; bump CACHE every time any cached file changes

privacy.html            Privacy policy (needed for both stores)
images/                 paper.svg (background), ink.svg (ink splotch), smiley.svg (smiley + EB initials)

assets/                 Source art for @capacitor/assets (icon-only, foreground/background, splash)
scripts/build-www.mjs   Copies the web files into www/ for Capacitor
capacitor.config.json   App ID, name, notification icon/colour, splash colours
package.json            Scripts: build, assets, sync, ios, android
ios/                    Native iOS project (generated by Capacitor, committed)
android/                Native Android project (committed)
docs/APP_STORES.md      Step-by-step Mac setup, signing, App Store Connect and Play Console
docs/HANDOFF.md         This file

```

`ios/App/App/public` and the Android `public` assets are gitignored; `npm run build && npx cap sync` recreates them.

Commands: `npm install`, `npm run build` (make `www/`), `npm run sync` (build + copy into the native projects),
`npm run ios` / `npm run android` (sync and open Xcode / Android Studio).

## 4. API calls and environment variables

**Environment variables: none.** There are no secrets, API keys or `.env` files. The Bookshop affiliate ID is a
public value in `content.json`.

**Network calls (the only ones):**
1. `GET https://emmaberat.github.io/iwrotetoday/content.json` (`cache: 'no-cache'`) to fetch the latest content.
   GitHub Pages sends CORS headers, so this also works from the native apps.
2. Outbound links only: `https://bookshop.org/a/<affiliateId>/<ISBN>` (falls back to
   `https://bookshop.org/book/<ISBN>` if the ID is empty).

No backend, no database, no analytics, no third-party scripts.

## 5. Data storage

Everything is on the device in `localStorage`. There is no account and nothing is sent anywhere.

| Key | Contents |
| --- | --- |
| `writingDays` | JSON array of days written, `"YYYY-MM-DD"` |
| `userStreak`, `lastCheckIn` | Legacy keys from an older version; migrated into `writingDays` on load |
| `content` | Cached copy of `content.json` |
| `reminderEnabled` | `"yes"` when the in-app reminder is on |
| `reminderTime` | `"HH:MM"`, default `20:00` |
| `introSeen` | `"yes"` after the first-run intro |
| `installTipDismissed` | Hides the "add to home screen" tip |

**Content loading order:** localStorage copy, then the `content.json` bundled with the app/site, then the live
fetch (validated with `isValidContent`; a broken live file is ignored).

**Quote selection:** `dayOfYear % list length`. Adding quotes to the list shifts every day's quote from that
point on. This is expected, but it means everyone's "today's quote" changes the day you add one.

**Consequence of local-only storage:** clearing site data or deleting the app loses the history, and there is no
sync between devices.

## 6. Auth

None. No sign-in, no accounts, no server. (If sync or accounts are ever wanted, that's a new backend, and the
privacy policy and both store questionnaires would need updating.)

## 7. Updating content (the common task)

Edit `content.json`, commit, push to `main`. The website updates within a couple of minutes; the apps pick it up
the next time they open online. Add new entries to the end of a list. Each novel quote needs
`text, author, book, year, gender, isbn` (10 or 13 digits). Celebrations are `{ "word": "...", "lang": "..." }`.
`bookshopAffiliateId` is currently `116684`.

Current content: 29 novel quotes, 17 celebration words, 22 unusual words, 6 craft quotes.

**Any change to `index.html`, images or icons:** bump `CACHE` in `sw.js` (currently `iwrotetoday-v24`), then
`npm run build && npx cap sync`, commit and push. App store users only get code/design changes through a new
store build.

## 8. Reminders and badge (native apps)

- The app schedules one local notification per day for the next 30 days (ids 1..30) at the chosen time.
- It skips today's if she has already checked in or the time has passed.
- It reschedules on app open, when the app becomes visible, on check-in, and when the time changes.
- If the app isn't opened for 30 days, reminders stop.
- Android: `SCHEDULE_EXACT_ALARM` is deliberately removed (`tools:node="remove"` in `AndroidManifest.xml`), so
  reminders can arrive a few minutes late. Small status-bar icon: `ic_stat_smiley`.
- Badge: notifications set for 18:00 or later carry `badge: 1`. Check-in or turning reminders off calls
  `removeAllDeliveredNotifications()` to clear it.
- Browsers keep the `.ics` calendar download.

## 9. Known bugs and open risks

1. **Native builds are untested.** The iOS and Android projects were generated on Linux. Neither Xcode nor the
   Android SDK was available, so nothing has been compiled or run on a device. First task on the Mac: build and
   run on a real iPhone and Android phone.
2. **Notifications and badge are only tested with a mocked plugin.** Check on real devices: permission prompt
   (Android 13+), delivery at the set time, red badge appearing and clearing, and that Android reminders aren't
   unacceptably late.
3. **The badge shows when the reminder arrives, not at exactly 18:00.** Phones can only update a badge when a
   notification arrives. A reminder set before 18:00 never shows a badge. A separate 18:00 "still time to write
   today" notification was offered but not built.
4. **Service worker caching:** home-screen users may need to close and reopen the app twice to see a new version
   (network-first, but the first open serves the cached page).
5. **Bookshop links:** the ISBNs for *Last Night at the Telegraph Club* (9780525555278) and *The Perks of Being a
   Wallflower* (9780671027346) have not been click-tested (Bookshop blocks automated fetches). The affiliate
   commission has not been confirmed in Bookshop's dashboard.
6. **Quotes shift when entries are added** (see section 5).
7. **Doodle overlap logic** (`updateDoodle`, MutationObserver, rect intersection) was tested at several phone sizes
   but is the most fragile piece of CSS/JS; recheck after layout changes.
8. **No automated tests** are committed.
9. **Content/rating:** two quotes include strong language and mature themes (set the age rating accordingly).

## 10. Decisions we made, and why

- **Single `index.html`, no framework:** simple to edit and host; matches how it began.
- **Capacitor wrapper, not a rewrite:** the same code becomes the website, the iPhone app and the Android app.
- **Content in `content.json` fetched live:** lets quotes and the affiliate ID change without store review.
- **Local-only data, no accounts:** private by default, no backend to run, easy privacy policy. Trade-off: no
  sync and no data recovery.
- **Real notifications in the apps (replacing the calendar file):** the `.ics` approach doesn't work inside an
  iPhone app, and native features reduce the risk of Apple rejecting the app as "just a website".
- **30 scheduled notifications, rescheduled on open:** avoids a background service and works offline.
- **No exact-alarm permission on Android:** avoids a sensitive permission; accepting small delays.
- **Celebration words:** one non-English word, no exclamation marks, language shown in small brackets, shown
  for about 2 seconds before the quote (same timing as the "treasure for your word hoard" message). Occitan and
  Catalan words included.
- **Intro wording:** "A daily tracker for your writing journey" (no "friendly").
- **Icon:** pen-blue smiley, slightly bolder, whiter button background, no ink splotch on the icon, no "did it!"
  writing. Initials "EB" in handwriting next to the smiley at about a third of its size, same colour.
- **Smiley hides when it would cover content** instead of overlapping it.
- **Bookshop.org affiliate links** (`bookshop.org/a/<id>/<ISBN>`); ID 116684.
- **App ID `com.emmaberat.iwrotetoday`.** It is permanent after the first store upload, so confirm it first.
- **Tip jar, later:** inside the apps it must use the stores' in-app purchases; on the website a Ko-fi-type link
  is fine. Wait until there is real usage. Paid-apps/banking/tax setup can be done in advance.
- **Monetisation expectation:** affiliate income alone is small; treat the app as a project/portfolio piece
  with a possible later upgrade.
- **Positioning vs competitors:** the simplest one-tap check-in with daily book quotes. No simple writing
  streak app with quotes was found. Closest: Blank Page (web), InkStreak, WritingHabit, Daily Writer, Word Keeper
  (heavier, subscription).
